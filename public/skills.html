The skill tree.

Sixteen skills, three branches. Levels come from finishing work that exercises the skill — never from a form field. Every skill caps at five levels, and the cap is enforced by the server, not suggested by this page.

NOT CONNECTED

The skill tree is not connected here.

Skill levels come from Student Icon's own API — the same service that records profiles and XP. This deployment publishes the static site only, so there is nothing for the tree to read from. It is not broken; it is simply not wired up here, and no player's data is affected.

The API is not answering on this machine. The tree loads from the same origin as this page, so the server needs to be running before it can appear.

  • The arcade — eleven games, no account, no API — is fully playable.
  • The landing page and the player profile pages are static and still load.
  • Accounts, XP and this tree are part of the full build, which needs the API running.

How a level happens

A passing learning challenge that names a skill adds one skill XP; every three XP is one level, up to that skill's cap. Level 0 means untrained, not locked — the tree is a record of what you have done, not a gate you have to earn your way through.
